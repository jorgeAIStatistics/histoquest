# HistoQuest

HistoQuest supports biology graduates and histology assistants preparing for the HTL exam. The goal is durable understanding of the complete specimen-to-slide workflow, including decisions the learner has not yet performed at the bench.

Retain the existing exam practice, spaced review, lessons, simulations, progress and Route 2 evidence tracker. Extend these with a sequential curriculum, an interactive specimen workbench, visual explanations, real attributed micrographs, and a field notebook. The default homepage is one ordered beginner-to-advanced course, with a clear starting activity and a next activity after each completion. Eight stages connect foundations to specimen preparation, special methods, IHC, integrated practice, laboratory planning and exam review. Optional tools are grouped in a separate Library.

Learning progress and simulated bench decisions are not documented clinical experience, verified competence, certification, or licensure. State licensure and ASCP certification are separate. Numerical exercise settings are explicitly illustrative rather than validated instrument protocols. All cases are synthetic. Content is author-checked, not independently expert-reviewed.

The application remains a static React/TypeScript application compatible with its existing GitHub Pages deployment. No external account or patient information is required. Preserve existing browser data and include new learning records in the versioned backup format.
